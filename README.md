# NIC Information Extractor – Python Mini Project

This project is a **Python-based mini project** developed using **Jupyter Notebook**.  
The application analyzes a Sri Lankan National Identity Card (NIC) number and extracts basic personal information such as **birth year** and **gender** based on NIC structure rules.

---

## Academic Context
- **Project Type:** Mini Project
- **Programming Language:** Python
- **Environment:** Jupyter Notebook
- **Focus Area:** String manipulation and logical condition handling

---

## Project Overview
The NIC Information Extractor accepts a Sri Lankan NIC number as input and processes it to determine the year of birth and gender of the individual.  
This project demonstrates basic Python programming concepts such as input handling, conditional logic, and string processing.

---

## Features
- Accept NIC number as user input
- Identify birth year from NIC
- Determine gender based on NIC value rules
- Display extracted information clearly
- Simple and readable logic implementation

---

## Logic Used
- NIC number format is analyzed using string slicing
- Gender is determined based on the day value logic
- Birth year is calculated using the extracted year segment

---

## Technologies Used
- Python
- Jupyter Notebook

---

## How to Run the Project
1. Install Python
2. Open Jupyter Notebook
3. Open the `.ipynb` file in this repository
4. Run the notebook cells
5. Enter a valid NIC number when prompted

---

## Project Scope
This project focuses on **basic data extraction and logic implementation**.  
It does not include database storage, GUI interfaces, or advanced validation mechanisms.

---

## Conclusion
This mini project demonstrates the use of Python programming fundamentals to solve a real-world problem.  
It highlights logical thinking, string processing, and simple algorithmic design using Jupyter Notebook.
